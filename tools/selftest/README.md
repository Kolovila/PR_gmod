# Автотест режима в игре

Тест запускает настоящий GMod с картой `rp_desert_conflict`, ставит в игру текущую ветку
(`gamemodes/testgm` и аддоны из `addons/`), гоняет проверки на сервере и пишет итог в консоль:
`[PR_SELFTEST] PASS …` / `FAIL …`, в конце `DONE pass=N fail=M`.

## Наборы

| Набор | Что проверяет | Время |
|---|---|---|
| `full` | всё ниже: `core` + `patrol` + `armor` + `minimap` | ~3 мин |
| `core` | база, магазин, точки захвата, сейвы, меню | |
| `patrol` | пеший патруль, редактор спотов и вариантов | |
| `armor` | патруль с танком Луны и Ми-24 | |
| `minimap` | мини-карта: союзник вдали, враг, далёкая точка, территории, скриншоты | ~40 с |
| `vehicles` | `tank` + `air` + `gepard` + `plane` + `strike` + `helistrike` + `dogfight` | ~4,5 мин |
| `tank` | танк Гредвича: экипаж-боты, наведение, переворот, награда | |
| `air` | Ми-24 со стрелком и OH-6: стрельба, заходы, рельеф, свои не бьют своих | ~1,5 мин |
| `plane` | штурмовик A-10: круг над патрулём, заходы через точку входа с пушкой, повторный заход, возврат севшего самолёта в небо | ~1,5 мин |
| `gepard` | Гепард патруля гибнет от пушки игрока (30 мм, затем 125 мм), взрыв simfphys не застревает | ~1 мин |
| `dogfight` | воздушный бой A-10 с манёвренной целью: огонь с упреждением, 10 попаданий, без тарана; вертолёты у патруля, стрелок бьёт | ~1 мин |
| `strike` | A-10 по игроку в технике: заходы «по технике», ракеты, урон | ~1 мин |
| `helistrike` | Ми-24 по технике: ракеты с места, управляемые ракеты стрелка | ~1 мин |

## Запуск

Отдельные копии игры для тестов (один раз и после обновления GMod):

```powershell
.\setup_instances.ps1 -Count 2
```

Они лежат в `D:\GModTest\inst1..N` (~5 ГБ каждая: тяжёлые архивы — ссылками на основную
установку). Тест в копии не трогает основную игру: можно играть, пока идут тесты. Чтобы игра
запускалась, когда тест уже идёт, в параметрах запуска GMod в Steam нужен `-multirun`.

```powershell
.\run_selftest.ps1 -Suite air -Instance 1        # один набор в копии 1
.\run_parallel.ps1 -Suites vehicles,full         # несколько наборов сразу, каждый в своей копии
.\run_parallel.ps1 -Suites air,air               # один и тот же набор дважды — ловить нестабильное
.\run_selftest.ps1 -Suite full                   # по-старому, в основной установке (игра закрыта)
```

Логи, скриншоты и копии сейвов — в `%TEMP%\pr_selftest`. В копию игры каждый раз кладутся
свежие данные из основной установки (`sv.db`, `data/pr_gamemode`), так что тест видит настоящие
споты и точки, а сам их не меняет.

Перед запуском удобно проверить скобки и `end` в Lua: `python check_lua.py файл.lua …`.

## Скан техники

`pr_selftest_scan_sv.lua` ничего не проверяет на «прошло/нет»: каждая машина по очереди выходит
в патруль против бота-цели, и в лог пишется одна строка `SCAN класс | …` — экипаж, сколько
проехала и на какой высоте была, выстрелы (пули, снаряды, ракеты), попадания, на сколько
градусов ствол смотрел мимо цели (`aim`), где рвались снаряды (`miss`), режимы ИИ, ошибки.

| Набор | Что гоняет |
|---|---|
| `scanair1`, `scanair2` | вертолёты новых паков, по половине списка (две копии игры) |
| `scanground1`, `scanground2` | наземная техника, по половине |
| `scanairfix` / `scanprefireair` | короткий список вертолётов для перепроверки (`AIRFIX`); `prefire` — через 18 с цель «заходит в дом» (домик из плит), пишется, куда ушёл огонь |
| `scanprefireground` | то же для наземки (`FIX`) |
| `scanaim` | один-два вертолёта (`AIMDEBUG`) и журнал наведения/кругов каждую секунду (`AIM …`, `AIR …`) |
| `scangroundaim` | БТР-80 и «Мардер» (`GROUNDDEBUG`): куда просим, куда смотрит ствол, поправка (`GAIM …`) |
| `scanfixground` / `scanfixshots` | список `FIX`; `shots` — ещё снимок каждой машины и состояние колёс (`WHEELS …`) |
| `scanfar` / `scanfarshots` | список `FIX`, цель в 4500: подъезжает ли машина на дальность огня (`dist to target A -> B`) и встаёт ли там; раз в 2 с — журнал езды (`DRIVE …`: до цели, режим, скорость) |
| `scanlong` | танки Гредвича и Луны, БТР-80А против цели в 5000–7000: замер падения снаряда (`DROP тип дальность:падение`) и попадания |
| `scanshots1`, `scanshots2` | вся наземка по половинам + снимок каждой машины |
| `scanplain` | машина из `PLAIN`, заспавненная обычным способом (без и с водителем) — сравнить с патрульной |

Во время скана камера в окне игры летает вокруг машины, которую гоняют: мышь — вращать,
колёсико — ближе/дальше, сверху — счётчики. `pr_scan_cam` в консоли — свободный полёт (V — noclip).

## Карта: туман и пути техники

`-Suite mapinfo` (~40 с): строки `MAPINFO` — туман и дальность прорисовки (`env_fog_controller`,
после правок из `gamemode/config/map.lua`), есть ли navmesh; проверки: туман из конфига встал,
путь танка по сетке техники (`gamemode/sv_nav.lua`) через город находится и по каждому отрезку
проходит корпус; снимок `fog_far` — вид вдаль.

`-Suite navgen` строит navmesh движка (`maps/<карта>.nav` в копии игры). На rp_desert_conflict
это больше часа (объединение областей идёт в один поток), а технике он не нужен — у неё своя
сетка. Оставлен на случай, если navmesh понадобится NPC.

## Снимок карты для мини-карты

```powershell
.\run_selftest.ps1 -Suite mapshot -Instance 1          # 16 плиток карты сверху (печатает SHOTS=…)
.\stitch_mapshot.ps1 -Shots <папка SHOTS>              # склеить в materials/test_gm_mat/minimap/<карта>.jpg
```

`stitch_mapshot.ps1` печатает строку с границами карты — её в `gamemode/config/minimap.lua`.
Нужно для новой карты или если карта изменилась.

## Как устроено

- `pr_selftest_lib.lua` — общая часть: шаги по очереди, `waitFor(таймаут, условие)` (проверка
  идёт, как только событие случилось, а не через фиксированную паузу), секции, постоянные места
  на карте (`FIXED_BASES`, `HARD_SPOTS`), переворот танка.
- `pr_selftest_sv.lua`, `pr_selftest_vehicles_sv.lua` — наборы (серверная часть),
  `pr_selftest_cl.lua` — клиентская (скриншоты, открытие окон).
- `pr_automap.lua` — в копии игры загружает карту, когда Workshop смонтирован (без `-hijack`,
  который мог бы попасть в игру пользователя).
- Режим видео GMod хранится в реестре, общем для всех копий: раннер запоминает его, пока тестов
  нет, и возвращает после последнего теста.
